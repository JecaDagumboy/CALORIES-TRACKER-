Calorie Tracker Pro

Calorie Tracker Pro is a web-based calorie tracking application designed to help users record and monitor their daily food intake.

Features

- User login interface
- Daily calorie tracking
- Manual food and calorie logging
- Food image upload and scanning simulation
- Calorie history
- Deleted item recovery through Trash
- Permanent trash deletion
- Food details modal
- Responsive mobile-style interface
- About App section
- Local storage for saving data

Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Lucide Icons
- Local Storage

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Enter an email and password on the login screen.
5. Start adding food items and tracking calories.

Notes

The food image recognition feature is a simulation for demonstration purposes. It does not use a real AI food recognition system.

User calorie records are stored locally in the browser using Local Storage.
